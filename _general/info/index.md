# Basic Game Information

This section is here to explain some small but important details about the SMBW speedrun that you will need to be aware of if you want to succeed in this game.

If you are new to SMBW, we ***heavily*** recommend you read through this section to avoid asking yourself questions later.

Along with the information supplied on the seperate pages, here is a list of even *more* useful information that isn't complicated enough for it's own page:
- Whenever you are falling straight down, ground pounding is only faster if the descent length is more than **9 blocks long**.
