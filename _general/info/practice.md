# Practice Tips

Practicing levels in SMBW is made extremely fast and easy even without any use of modifications.

Here is a basic list of tips you should know for how to practice effectively

- Have a **100% save file** so you have access to every level in the game.
- Grab power-ups you need from **Search Party: Item Park** and then leave from the left side. (This works extremely similarly to *Top Secret Area in Super Mario World*)
- Use the **L button to activate the Course menu, to quickly select courses of interest**.
- Use **Pause -> Restart** to try levels again or save yourself from deaths.

It's as simple as that! Just grab your power-ups, select a level, and play!

Unfortunately, one drawback of SMBW in terms of practicing is the game's mediocre **save system**, which locks one save per profile on your Switch, with *zero way to copy and paste files.* Furthermore, that plus the *lack of autosave* makes it almost impossible to do RTA Individual World (IW) speedruns for full-game practice without the use of mods.

That means if you want to do IWs, you'll have to do it in a post-game file, or use a save editor on a modified Switch to copy and paste files that way. This isn't a massive deal, but it is quite annoying for those that prefer having accurate IW comparisons.

## Practice Mod

Now, for those interested, we *do* have a Practice Mod that you can use on a modified Switch 1 (or emulator) using the v1.0.0 of the game. You can download it [here](https://github.com/notCodek/MarioWonderSpeedrunPracticeMod/releases/tag/Releases)!

What does this mod do exactly? Well, for the time being, all it really does is add additional warp pipes throughout the levels to quickly practice specific sections that may be deep into certain levels. This can save a lot of time in practice sessions when you want to just practice one hard segment.

It also adds an **In-Game Timer** to each level which can be helpful for comparisons, however since it uses the base IGT that the game uses for Wiggler Races, the timer freezes during power-up and pipe transitions, making it inaccurate to RTA timing and as such is ***NOT*** allowed for Individual Level submissions.

This mod is still fairly barebones, only including levels from Any% No Major Glitches and some additional ones. Along with the fact that there currently isn't any custom coding tools for SMBW, we can't currently add any important feature like save states, accurate IGT, power-up hotkeys, or anything of the sort.

For these reasons listed above, ***we don't personally recommend you use the Practice Mod unless you are at a top level/extremely familiar with the game, or you REALLY want to.*** The reason we say this is because it is important to practice *all* of a level until it becomes second nature, and using the practice mod to exclusively practice "hard" segments can compromise your skill/familiarity with the "easy" segments.
