# Getting Started

Welcome to Super Mario Bros. Wonder speedrunning! We hope you enjoy your time with this *wonderful* game!

This page is here to help you get set-up and ready to take a deep dive into what this game has to offer, so let's get right into it!

Once you're all ready to go, we recommend checking out our [Basic Game Information](https://notcodek.github.io/TestProjectWonderTut/general/info/index/) section to understand the finer details of how this game works before you hop into learning a [full-game category](https://notcodek.github.io/TestProjectWonderTut/general/categories).

## Game Rules

You can find the full list of game rules [here](https://www.speedrun.com/smbw?h=any&rules=game&x=9kvg5v3k), but just in case, we'll summarize the most important ones here.

For the most part, our ruleset is extremely standard. We use RTA timing (except for our longer categories), which means that the timer cannot be paused at any time and runs are completed in one sitting. You can't use multiplayer (unless stated otherwise), online mode enabled, or assist mode. "Easy Mode" characters such as Nabbit and Yoshi are completely legal to use, however.

However, something important to mention is that **we have outright banned emulation for the leaderboard.** You will have to play the game on an official release of SMBW as well as a Nintendo Switch 1 or Switch 2. Information on the differences between consoles, digital/physical, and game versions can be found [here](https://notcodek.github.io/TestProjectWonderTut/general/info/game_versions/).

The last main thing to mention is that **all runs MUST be recorded (with audio) in order to be verified!** Read the following section if need assistance doing so.

## Recording Your Runs

As mentioned in the previous section, ***All*** runs on the leaderboard require video proof with audio in order to be verified!

This means you are going to need some hardware and software in order to do so

#### Software

*LiveSplit* - [Download Here](https://livesplit.org/downloads/)

While technically not required, it is extremely recommended to use LiveSplit when you do full-game runs as a timer to keep track of pace. Most communities use LiveSplit for this purpose, so while seasoned speedrunners would already have this installed and ready to go, we decided to include this regardless

*Open Broadcaster Software (OBS)* - [Download Here](https://obsproject.com)

The standard streaming software, used for recording or streaming your runs. Setting up OBS from scratch is outside of the scope of this guide, but just know there isn't any specific settings that you need to have in order to properly record this game. Just make sure you're recording in **60fps** (if your capture card supports it) as that is the frame rate this game runs on.

#### Hardware

The only hardware you really need for submitting your runs (outside of a computer for recording) is **a way to capture your Switch's video**, which is typically done through *capture cards*.

Since the Switch/Switch 2 is a modern console that uses HDMI for video, you'll need an HDMI capture card to intercept the video before it gets displayed on your monitor or TV.
